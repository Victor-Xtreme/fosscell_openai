LEVEL 1
The six main jobs
1. Read server logs.
2. Extract timestamps, endpoints, statuses and latencies.
3. Group requests by hour and endpoint.
4. Count server errors.
5. Calculate latency percentiles.
6. Generate a summary report.

The most important thing to understand:
This program is not simply reading a text file. It is an optimized data-processing pipeline that combines parallel computing, 
efficient memory management, sorting algorithms and statistical calculations to analyze large server logs.
